# Original research archive

These are the original applications, notebooks, weights, and optional Pico W experiment. They are preserved for provenance and are **not dependencies of the current product**. See the [new application](../README.md).

- `EEG_Recorder/`: Python recorder and original Arduino firmware.
- `Mind-Nav-App/`: Tkinter tester and keyboard.
- `Notebook/`: training notebooks, comparison architectures, CSV, and Python weights.
- `Microcontroller/`: optional MicroPython Pico Wi-Fi LED experiment.
- `ORIGINAL_README.md`: original project description.

Old scripts and README links describe the original directory layout; use Git history to reproduce that environment. Root `Data/` recordings and `Media/` images remain in place. No recording or model artifact was deleted. New CSV import/training runs in Rust; Python `.joblib` and PyTorch `.pt` files require retraining in Model Studio.
